# Plant Product Images

This folder contains images for the nursery plant products.

## Rose Images

To add the rose flower images, please save them in this directory with the following names:

- **rose.jpg** - First rose image (outside greenhouse shot)
- **rose2.jpg** - Second rose image (inside greenhouse shot with potted roses)

These images will be displayed in the product card with a scrollable image carousel showing both views.

## Image Carousel Features

- View multiple images per product by clicking the arrow buttons (❮ ❯)
- See the current image number (e.g., "1 / 2")
- Category badge shows on the first image
- Images are 300px in height and automatically sized

## File Structure

```
public/
└── assets/
    └── products/
        ├── rose.jpg          (Add your first rose image)
        ├── rose2.jpg         (Add your second rose image)
        └── README.md
```

## How to Add Images

1. Place the rose flower images in this directory (`public/assets/products/`)
2. Name them exactly as `rose.jpg` and `rose2.jpg`
3. Restart the development server to see the changes

The application will automatically load and display these images in the product carousel.
